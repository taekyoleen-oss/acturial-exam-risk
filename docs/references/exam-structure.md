# 보험계리사 시험 과목 구조

## v1 범위: 2차 계리리스크관리 단일 과목

### 시험 형식
- **형태**: 주관식 논술형/계산형 (선택지 없음 — 답안 직접 작성)
- **과목**: 계리리스크관리 (2차)
- **시행기관**: 금융감독원 (보험계리사 자격시험)

### 주요 시험 범위 (계리리스크관리)

| 대분류 | 세부 주제 |
|-------|---------|
| 리스크 관리 일반 | 리스크 정의, 분류, 관리 프로세스, ERM |
| 시장리스크 | VaR, CVaR, 금리·주가·환율 리스크, 민감도 분석 |
| 신용리스크 | 부도확률, LGD, EAD, 신용등급, 거래상대방 리스크 |
| 운영리스크 | 바젤 기본지표법·표준방법, 내부모형, 내부통제 |
| 유동성리스크 | 유동성 커버리지 비율, 조달리스크, 시장유동성 |
| 보험리스크 | 언더라이팅, 사망·장수·질병·재해·저축리스크 |
| ALM | 듀레이션·볼록성, 면역화, 현금흐름 매칭 |
| 지급여력 | K-ICS, RBC, ORSA, 규제자본 |
| 재보험 | 비례재보험, 초과손해재보험, 출재·수재 |
| 리스크 측정 | 스트레스테스트, 시나리오 분석, 내부모형 |

### 기출 데이터 구조 (DB)
- `subject`: `'리스크관리'` (v1 고정값)
- `session`: `'2차'`
- `year`: 출제 연도 (예: 2020, 2021, ..., 2024)
- `question_no`: 문항 번호

### 참고
- 실제 시험 안내: 금융감독원 보험계리사 자격시험 페이지
- 한 회차 문항 수: 약 40문항 (연도별 상이)
- 론치 목표 데이터: 150~500문항 (3~10년치 기출)
